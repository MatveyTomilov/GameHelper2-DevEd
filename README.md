# GameHelper2 DevEd

GameHelper2 DevEd — независимая производная версия [GameHelper2](https://github.com/Gordin/GameHelper2) для Path of Exile 2. Этот приватный репозиторий хранит собственный код ExchangeTrader, диагностику, сценарии восстановления и мониторинг upstream. Для полной Windows-сборки нужна отдельная локальная интеграционная копия исходников. Перечень и причины приведены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Локальная сборка

Требуются Windows x64, PowerShell 7.2+, .NET SDK из `global.json`, Git и локальная интеграционная копия `GameHelper2-DevEd-Local` на базе `402f978`. Сценарий собирает отсоединённый worktree в `artifacts/local-build` и выдаёт путь к Release и SHA‑256.

```powershell
./dev/build-local.ps1 -LocalSource 'E:/Gamegof/GameHelper2-DevEd-Local'
```

Полный пакет подключает хост и локально восстановленные MCP Bridge и RunecraftHelper. Прежний рабочий профиль хранится отдельно. Шаблон `config.example.json` показывает настройки для запуска диагностики. Не используйте на проверке ключи `-AllowAutomation` и `-StartExchangeTrader`.

## Разработка и релизы

- `main` содержит проверенные снимки. `develop` используется для интеграции собственных исправлений.
- `feature/*` — новые функции, `fix/*` — исправления, `upstream/*` — выборочный перенос и отдельное состояние мониторинга.
- Релизы DevEd нумеруются как `vMAJOR.MINOR.PATCH`. Первый локальный пакет — `v0.1.0`. Техническая версия хоста `2.9.0` сохраняет совместимость сборок плагинов.
- Перед публикацией проверяйте манифест, SHA‑256, зависимости, привязку к версии клиента и результат smoke-тестов. Полный бинарный пакет хранится локально, пока права на все его компоненты не подтверждены.
- Для отката остановите тестовый экземпляр, запустите проверенный архив из отдельного каталога и подключите сохранённый ранее профиль. Установка распаковывается отдельным комплектом DLL.

Происхождение описано в [CREDITS.md](CREDITS.md). Для обновления клиента используйте [PATCH_RECOVERY.md](PATCH_RECOVERY.md), для выборочного переноса исправлений — [UPSTREAMS.md](UPSTREAMS.md).
