Для упакованного локального приложения версии NuGet зафиксированы в `packages.lock.json` и `dev/locks`. В GitHub передаются только метаданные зависимостей, а пакеты восстанавливаются локально. В их числе [Newtonsoft.Json 13.0.3](https://www.nuget.org/packages/Newtonsoft.Json/13.0.3), [ImGui.NET 1.91.6.1](https://www.nuget.org/packages/ImGui.NET/1.91.6.1), [ClickableTransparentOverlay 11.1.0](https://www.nuget.org/packages/ClickableTransparentOverlay/11.1.0), [Coroutine 2.1.5](https://www.nuget.org/packages/Coroutine/2.1.5), [ProcessMemoryUtilities.Net 1.3.4](https://www.nuget.org/packages/ProcessMemoryUtilities.Net/1.3.4) и [ImageSharp 3.1.12](https://www.nuget.org/packages/SixLabors.ImageSharp/3.1.12). Условия ImageSharp проверяются по [Six Labors Split License](https://sixlabors.com/pricing/). Уведомления зависимостей остаются частью их пакетов. [Ghidra и Temurin](dev/tools.json) устанавливаются как внешние проверяемые инструменты по SHA‑256. Их архивы и бинарники в GitHub не передаются.

Доступность исходников на GitHub не даёт общего права загружать их в отдельный репозиторий. Для снятия ограничения нужны лицензия конкретной ревизии или разрешение правообладателя.
